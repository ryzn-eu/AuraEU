How to install Aura

On iOS (Safari)

  1. Tap the Share button at the bottom.
  2. Scroll down the menu.
  3. Select Add to Home Screen.
  4. Tap Add in the top right.

On Android (Chrome)

  1. Tap the Menu (⋮) in the top right.
  2. Select Install app or
    Add to Home Screen.
  3. Confirm by tapping Install.

On PC / Mac

  1. Look in the address bar in the top right.
  2. Click the Install Aura icon.
  3. Confirm by clicking Install.
